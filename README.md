# 360 Tech Engineering — homepage redesign

A static, responsive homepage concept for 360 Tech Engineering, based on information published at [360tech.ie](https://360tech.ie/). The attached original logo is retained. The industrial hero image is an AI-generated conceptual visual, not a photograph of a company project.

## Run locally

Open `index.html` in a browser or serve the repository root with any static server. No build step or backend is required. Contact links use the business's published telephone numbers and email address. Service links lead to the original website.

## GitHub Pages

The site uses relative paths and can be published from the repository root on a GitHub Pages source branch. In repository **Settings → Pages**, choose a branch and `/ (root)` as the source. The page includes a `noindex` directive because this is a redesign demo. Google Fonts are loaded remotely, with sans-serif fallbacks.

The client and supplier logo artwork was sourced from the original site's indexed images. Two security partner logos reference the original site directly; their names remain visible if those remote images cannot load. These marks remain the property of their respective owners.
